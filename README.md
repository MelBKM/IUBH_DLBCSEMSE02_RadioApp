# RadioApp

Dieses Repository enthält das im Rahmen des IU-Moduls **DLBCSEMSE02 – Seminar Software Engineering** entwickelte Gruppenprojekt.

Die Android-Anwendung bildet grundlegende Funktionen einer Radio-App ab, darunter die Anzeige von Songinformationen, Playlist- und Moderatorbewertungen sowie die Verarbeitung von Musikwünschen.

## Technologien

- Android Studio
- Java
- JSON
- Git / GitHub

## Projektart

Studienprojekt im Rahmen des Bachelorstudiums an der IU Internationalen Hochschule.

## Hinweis

Das Repository wurde für die Abgabe und Bewertung öffentlich bereitgestellt.
